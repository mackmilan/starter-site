# Adaptador para ferramentas sem carregamento automático

Você está trabalhando no frontend do Site Starter. Leia `docs/ai/README.md`, `docs/ai/project-context.md`, `docs/ai/decisions.md` e `docs/ai/memory-log.md` antes de alterar o projeto.

Use `docs/ai/` como fonte canônica de contexto. Preserve mudanças existentes no worktree, confirme o código atual antes de assumir um comportamento, não edite arquivos gerados manualmente e nunca registre ou exponha senhas, tokens, chaves, cookies, sessões, valores de `.env` ou dados pessoais.

Ao concluir, revise se há conhecimento durável novo, atualize a documentação técnica afetada, execute `npm run docs:check` e relate separadamente validações locais, validações do cliente gerado e qualquer verificação de backend que não tenha sido executada.
